# AI Chatbot

A simple AI chatbot built with Python and Gradio using the Hugging Face API.

## Technologies

* Python
* Gradio
* Hugging Face
* Qwen

## Features

* Chat with an AI model
* Simple web-based interface
* Natural language responses

## How to Run

```bash
pip install -r requirements.txt
python app.py
```

A Hugging Face API token is required to run the chatbot.
